# ESQLNew - Excel 批量导入 MySQL 工具

一个基于 .NET Framework 4.6.2 + WinForms 的桌面工具,用于将本地 Excel 文件批量导入远程 MySQL/MariaDB 数据库,支持动态连接配置、列映射预览、可视化进度与错误明细导出。

## 功能特性

- **动态数据库连接**:支持表单模式(服务器/端口/账号/密码/数据库)与完整连接串模式两种配置,配置持久化到 `%APPDATA%\ESQLNew\config.json`
- **测试连接**:一键测试连通性,成功/失败弹窗提示
- **数据库/表选择**:连接成功后自动拉取数据库下拉列表(默认隐藏系统库,可切换显示),选库后自动列出该库全部表,支持下拉搜索与手动输入
- **中文表头映射**:内置 Excel 中文表头 → 数据库英文字段映射表,自动匹配列;未映射列显示为"未匹配"
- **匹配预览**:预览列映射关系 + 前 100 行样例数据(仅显示匹配列)
- **批量导入**:多值 INSERT 批量写入,批大小与提交频率可调;批量失败自动降级为逐行插入并记录失败明细
- **可视化进度**:进度条 + 已处理/总数/成功/失败实时计数,导入完成后弹出汇总报告(耗时/行每秒/批次数)
- **失败明细导出**:将失败行号与错误信息导出为 CSV 文件
- **本地日志**:导入历史与失败明细写入本地 SQLite 数据库(`%APPDATA%\ESQLNew\logs.db`),按保留天数自动清理
- **自动主键生成**:目标表 `id` 为非自增主键且 Excel 未提供时,自动从 `MAX(id)+1` 顺序生成

## 技术栈

| 组件 | 技术 |
|------|------|
| 运行时 | .NET Framework 4.6.2 (WinForms) |
| MySQL 驱动 | MySql.Data 8.0.33 |
| Excel 读取 | ExcelDataReader 3.6.0 (流式读取,内存友好) |
| 本地日志 | System.Data.SQLite 1.0.118 |
| 配置序列化 | Newtonsoft.Json 13.0.3 |
| 测试框架 | xUnit 2.4.2 |

## 项目结构

```
src/ESQLNew/
├── Core/          # 配置、连接串构建、数据库元数据查询
├── Excel/         # Excel 流式读取(工作表/表头/数据行)
├── Import/        # 列映射、值转换、批量写入、导入编排
├── Logging/       # SQLite 日志存储
├── MainForm.cs    # 主窗体
└── MainForm.Tabs.cs  # 连接/导入/日志三个页签
tests/ESQLNew.Tests/   # xUnit 单元测试
```

## 构建与运行

要求:Windows + .NET Framework 4.6.2 或更高(.NET SDK 用于构建)。

```bash
dotnet build ESQLNew.sln
dotnet test ESQLNew.sln
```

运行产物:`src/ESQLNew/bin/Debug/net462/ESQLNew.exe`(也可 `dotnet run` 或直接运行 exe)。

## 使用说明

1. **连接 Tab**:填写服务器/端口/账号/密码(或切换"连接串模式"粘贴完整连接串)→ 测试连接 → 自动列出数据库 → 选择目标数据库
2. **导入 Tab**:选择本地 Excel 文件(自动用第一个工作表名预填目标表)→ 选择目标表(或手动输入)→ 匹配预览确认列映射 → 开始导入
3. **日志 Tab**:查看历史导入记录与失败明细

## 性能

在 60,391 行 × 81 列的真实业务数据上实测,约 1100 行/秒,三组批大小配置性能一致,推荐批大小 2000 / 提交频率 5000(默认值)。详见 `docs/perf-report.md`。
